# IVA — portfolio

Static portfolio site of IVA (AI Engineering & Automation) in three languages: Russian, English and Turkish.

- RU: https://7lver10.github.io/iva-portfolio/?lang=ru
- EN: https://7lver10.github.io/iva-portfolio/?lang=en
- TR: https://7lver10.github.io/iva-portfolio/?lang=tr

On the first visit the language follows the browser (ru → RU, tr → TR, anything else → EN); the choice is remembered.
